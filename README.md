# SQL Analytics Projects

This repository is a SQL-focused analytics portfolio covering practical business analysis across multiple domains. It includes a complete e-commerce analytics project and planned folders for banking and hospital analytics work.

## Repository Structure


## Projects

### Ecommerce-Analytics

A complete SQL analytics project based on an e-commerce dataset with 5,000 orders. It covers:

- sales and revenue analysis
- customer behavior and segmentation
- product and category performance
- payment and delivery analysis
- business questions and actionable insights

Files in this folder include the dataset, schema, beginner/intermediate/advanced SQL scripts, business questions, and a project README.

See: [Ecommerce-Analytics/README.md](./Ecommerce-Analytics/README.md)

### Banking-Analytics

This folder is reserved for a banking analytics project focusing on financial KPIs, transaction patterns, customer risk, and business performance metrics.

### Hospital-Analytics

This folder is reserved for a healthcare analytics project covering patient trends, operations, service quality, and clinical performance metrics.

## Skills Covered

- SQL querying and data cleaning
- Aggregations and filtering
- Date and business KPI analysis
- Window functions and ranking
- Customer and product segmentation
- Business storytelling through SQL-driven insights

## Tools Used

## Notes

The repository is designed as a growing portfolio of SQL case studies. The e-commerce project is currently populated and the banking and hospital folders are set up for future project additions.
